A premium, single-page personal portfolio website built for **Saurav Kumar**, an MBA student specializing in **Finance and Marketing** at CT Group of Institutions. Inspired by high-end modern web design aesthetics, this portfolio perfectly combines analytical rigor with consumer-driven strategies.

---

## 🌟 Key Features & Modern UI Enhancements

- **⚡ High-Performance Fullscreen Page Loader**: A minimal, sleek `0.8s` initial load screen featuring a pulsing teal monogram avatar.
- **📈 Animated Count-Up Stats**: Custom `easeOutQuart` easing counters in the Hero section animating dynamically when scrolled into view.
- **🎨 Premium Teal Gradient Borders**: Shifting teal-to-cyan gradient borders (`#0f766e` → `#06b6d4` → `#0f766e`) on all project, experience, and service cards, as well as the navbar logo.
- **🟢 Floating WhatsApp Action Button**: A `64px × 64px` fixed action button at the bottom-right corner with custom tooltips, hover scaling, and load bounce animations.
- **⏳ Pulsing Timeline Dots**: Interactive timeline badges in the Education grid featuring staggered `2s` infinite pulse rings.
- **✨ Custom Desktop Trailing Cursor**: A smooth 8px teal dot cursor following mouse movements with a trailing easing effect.
- **📜 IntersectionObserver Scroll Reveal**: Premium fade-in and slide-up transitions as sections enter the browser viewport.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic and accessible single-page markup.
- **Tailwind CSS (CDN)**: Modern utility-first styling with custom dark/light theme configurations and curated teal accents.
- **Alpine.js (CDN)**: Lightweight, reactive JavaScript component logic for scroll tracking, active section highlighting, mobile menu toggling, and form interactivity.
- **Google Fonts (Inter)**: Clean, professional typographic hierarchy.
- **FontAwesome 6.4.0**: Scalable vector icons for all UI elements.
